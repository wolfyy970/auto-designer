Build a habit tracker app. Core features:

- Set up multiple habits (daily, weekly, custom frequency)
- Mark each habit complete each day with a single tap
- Show streak counters per habit
- Daily push reminder at user-set time
- Weekly progress chart showing 7-day completion rate
- 30-day calendar view per habit (filled square for done, empty for missed)
- Social sharing of streaks to Twitter / Instagram
- Premium tier ($4.99/month): unlimited habits, custom themes, advanced analytics

The MVP should ship with these features. Visual style: clean, minimalist, mobile-first, similar to popular habit apps in this category (Streaks, Habitica, Way of Life).
