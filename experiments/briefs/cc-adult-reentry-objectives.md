The design must support persistence through the first term, by which point the learner has either built a workable rhythm or is sliding away. The failure mode to avoid: an enrollment-friendly experience that fades when the actual class work begins.

The design must surface the institution-specific information the learner needs at the moment they need it — payment deadlines, textbook codes, parking, advisor contact, registration windows, financial-aid award letters. The failure mode to avoid: generic guidance that misses the institution's specifics.

The design must work for the adult learner's life (job hours, childcare, transportation). The failure mode to avoid: an experience that assumes the institution's daytime hours.

The design must build the learner's social network of peers, advisors, faculty, mentors. The failure mode to avoid: isolating the adult learner in an online-friendly experience that bypasses the human relationships that drive persistence.

The design must respect the learner's prior credentials and prior experience. The failure mode to avoid: treating the 45-year-old returning learner like an 18-year-old first-time student.
