The surface should put the manager's own observations of this specific employee — notes, Slack threads, project moments, prior 1:1 notes — within immediate reach as they write, so the review is built from what actually happened rather than from generalization. The failure mode to avoid: a notes surface so dense it competes with the writing surface, leaving the manager scrolling through history instead of drafting.

The relationship between an aggregate judgment ("strong on cross-functional collaboration") and the specific moments that ground it should be visible to the manager while writing. The failure mode to avoid: connections so strongly suggested that the manager rubber-stamps the inferred link without verifying it actually fits, producing a confident review the manager has not actually thought through.

The surface should hold the calibration context — what scale this organization uses, how other managers tend to use it, what calibration the review will face — so the manager can locate this review against the standard. The failure mode to avoid: calibration cues so prominent the manager writes toward the curve rather than toward the employee, distorting reviews to fit an expected distribution.

Where the surface offers AI-generated language, the source — the manager's own notes, prior feedback, the employee's own writing — should be visible alongside the suggestion, and the manager should be the one who commits anything to the document. The failure mode to avoid: AI-suggested phrasing the manager accepts without recognizing it as language they would not have written themselves, smuggling in tone and assumptions the manager has not endorsed.

The drafting experience should anticipate the conversation that follows — the surface should make it easy to leave the written document and rehearse, or annotate, how the review will be delivered in person. The failure mode to avoid: producing a polished document optimized for the form's reading pattern but unreadable as something to speak aloud, leaving the manager to translate the document at the 1:1.
