The design must result in a properly-issued license before the state's deadline. The failure mode to avoid: producing a smooth experience right up to the in-person DMV visit, where the user is sent home for missing documentation.

The design must surface exactly what the user needs to bring and in what form, for the user's specific state and circumstances. The failure mode to avoid: generic guidance that misses the user-specific case (non-citizen, name-mismatch, REAL ID upgrade, recent name change).

The design must respect the cognitive load of the move overall. The failure mode to avoid: a tool that demands the same attention a complete relocation deserves but for one task.

The design must produce predictable wait times — when to make an appointment, when the DMV is less busy, how long the in-person visit will take. The failure mode to avoid: setting expectations the DMV's reality fails to meet.

The design must explain the temporary-license window (paper printout vs hard-copy delay) and what the user can and cannot do with the temporary form. The failure mode to avoid: silent ambiguity that leaves the user unable to fly during the multi-week wait.
