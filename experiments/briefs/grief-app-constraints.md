Working memory capacity is measurably reduced during active grief — research suggests 20–40% shrinkage under stress. The interface must not burden users with setup tasks, configuration wizards, or complex navigation during early sessions. Any state that must be carried across interactions should be externalized and visible (e.g., clear progress indicators, saved positions, persistent filters) rather than requiring recall. Limit visible options to 4–6 at any decision point; rank by likelihood and defer non-essential choices.

Privacy is not a feature but a foundational requirement. Users have explicitly identified that grief content appearing in social feeds, search history, or shared device accounts is a dealbreaker. The design must guarantee that content remains private by default — no social graph integration, no public sharing pathways, no loosely scoped data retention. This constraint is hard: any design that requires visible or shared components will face adoption resistance.

The experience must avoid both prescriptive flows and generic prompts. Users rejected "step 4 of 7" sequences and hollow "how are you feeling today?" check-ins equally — both signal that the tool doesn't understand their specific journey. Avoid funnel logic entirely: no onboarding sequences that assume a linear path, no prompts that position themselves as steps to complete. Every interaction should feel like an available option rather than a required action.

Interface complexity must be minimized to match the high-arousal state of grief. Following Yerkes-Dodson, performance degrades when arousal is elevated — the interface should simplify, enlarge critical actions, and confirm irreversibles before execution. Use muted defaults with single-point salience for primary actions; avoid visual noise that competes with the user's emotional state. Response latency should stay under 400ms wherever possible to maintain trust — unresponsiveness mirrors the hollow feel of generic journaling tools.

Content and copy must provide specific scent rather than generic scaffolding. Users need concrete, verb+noun labeled actions that reflect understanding of grief (e.g., "Write a memory" rather than "Create entry"). Pair icons with labels to support reduced recognition memory. Avoid redundant visual decoration; reserve high-intensity treatments for genuine state changes, not decoration. The design should feel like a quiet, reliable personal space — not a feed, community hub, or engagement-optimized product.
